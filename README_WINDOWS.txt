Welcome to the College Certificate Management System!

--- QUICK START FOR WINDOWS ---
Option 1: Direct Double-Click
- Double-click "CollegeCertificateManagementSystem.exe" to launch directly!

Option 2: 1-Click Installer
- Right-click "install_windows.bat" and run it.
- This creates a Desktop shortcut with the application icon automatically.

Option 3: Batch Launcher
- Double click "run.bat" to start with console logging enabled.

--- SYSTEM REQUIREMENTS ---
- Windows 10 or Windows 11 (64-bit / 32-bit)
- Java Runtime Environment (JRE/JDK 17 or higher)
  If not already installed, download free from:
  https://adoptium.net/
